KRCS Nairobi County Branch RCAT Trivia 2026 - Hosting Notes

Fastest public hosting option:
1. Go to https://app.netlify.com/drop/
2. Sign in or create a free Netlify account.
3. Drag the rcat-trivia-quiz folder, or the rcat-trivia-quiz-deploy.zip file, onto the upload area.
4. Netlify will give you a public website link.
5. Open the link and add #quiz at the end for participants.

Examples:
Participant link: https://your-site-name.netlify.app/#quiz
Admin link: https://your-site-name.netlify.app/#admin

Admin access code:
RCAT2026

Important:
This static version can be hosted publicly, but participant results are currently saved in each browser's local storage.
That means the admin dashboard will not collect results from different phones/computers until a shared backend/database is added.
Use Firebase or Supabase for the production version where all participant submissions sync to one admin dashboard.
